Um resumo sobre objetivo desse Portifólio.

que é o projeto
Este projeto é uma plataforma web responsiva dedicada à catalogação detalhada da biodiversidade vegetal global.
O site funciona como um dicionário digital, organizando informações complexas de forma acessível e intuitiva para o usuário final.
Propósito e Contexto

  • Trabalho de Conclusão de Curso (TCC) em Desenvolvimento de Sistemas.
  • Democratizar o acesso ao conhecimento científico e popular sobre botânica.
  • Centralizar dados dispersos em uma única base digital organizada.

Principais Funcionalidades
  • Catálogo completo: busca por nomes científicos e populares de plantas.
  • Guia de cultivo: instruções detalhadas sobre habitat e cuidados específicos.
  • Fichas técnicas: dados sobre propriedades medicinais ou alertas de toxicidade.
  • Interface responsiva: adaptada para navegação em celulares, tablets e computadores.
